⚙️ Hubungkan Google Sheet ⚙️

Kirim nilai pretest, posttest, dan aktivitas siswa langsung ke spreadsheet Anda!

Cara Menghubungkan Google Sheet:

  1. Buka Google Sheet Anda: Buka Google Sheet
  2. Pada menu atas Google Sheet, klik Ekstensi (Extensions) > Apps Script.
  3. Hapus semua kode bawaan di dalam editor, lalu salin dan tempel kode script berikut: 
    function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var data = JSON.parse(e.postData.contents);
  var type = data.type;
  
  // Tentukan nama sheet berdasarkan kategori
  var sheetName = "Aktivitas & Refleksi";
  if (type === "Pretest") {
    sheetName = "Pretest";
  } else if (type === "Posttest") {
    sheetName = "Posttest";
  }
  
  // Ambil sheet atau buat jika belum ada
  var sheet = ss.getSheetByName(sheetName);
  if (!sheet) {
    sheet = ss.insertSheet(sheetName);
  }
  
  // Buat header kolom otomatis jika sheet masih kosong
  if (sheet.getLastRow() === 0) {
    if (type === "Pretest" || type === "Posttest") {
      sheet.appendRow(["Tanggal & Waktu", "Nama Siswa", "Pertemuan", "Nilai Ujian", "Analisis Jawaban"]);
    } else {
      sheet.appendRow(["Tanggal & Waktu", "Nama Siswa", "Pertemuan", "Kategori", "Skor/Respon", "Tanggapan/Detail"]);
    }
  }
  
  // Tambahkan data baris baru
  if (type === "Pretest" || type === "Posttest") {
    sheet.appendRow([
      new Date(),
      data.name,
      data.meeting,
      data.score,
      data.details
    ]);
  } else {
    sheet.appendRow([
      new Date(),
      data.name,
      data.meeting,
      data.type,
      data.score,
      data.details
    ]);
  }
  
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
  4. Klik ikon disket (Save project) di atas editor Apps Script.
  5. Klik tombol Terapkan (Deploy) > Terapkan Baru (New deployment).
  6. Klik ikon roda gigi (Select type) di sebelah "Terapkan Baru", lalu pilih Aplikasi Web (Web app).
  7. Ubah kolom Siapa yang memiliki akses (Who has access) menjadi Siapa saja (Anyone). Ini penting agar siswa dapat mengirim nilai secara otomatis!
  8. Klik tombol Terapkan (Deploy), lalu setujui otorisasi jika diminta oleh Google.
  9. Salin URL Aplikasi Web (Web app URL) yang diberikan (formatnya: https://script.google.com/macros/s/.../exec).
